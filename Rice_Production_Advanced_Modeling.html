▸ MODELLING PRINCIPLES

This notebook builds 5 predictive models to forecast rice production in Sri Lanka, resolving all data leakage and indexing issues from previous work:

  1. Time Index: Chronological PeriodIndex starting in 1950Q2 (semi-annual Yala/Maha).
  2. Validation: Train-test split by time (Train up to 2018Q4, Test 2019Q2–2024Q2) to prevent data leakage.
  3. Outliers: Scaled safely using RobustScaler (no row dropping, preserving time series order).
  4. Future Exog: Future weather/harvested acres predicted using a helper model, rather than repeated.

# tag: baseline_sarima
# Fit SARIMA on log production
y_train_log = np.log(train_df["Production (*000  Mt.)"])
y_test_log  = np.log(test_df["Production (*000  Mt.)"])

sarima_model = SARIMAX(
    y_train_log,
    order=(1, 1, 1),
    seasonal_order=(1, 1, 0, 2),
    enforce_stationarity=False,
    enforce_invertibility=False

Model 5: Hybrid Model (SARIMAX + RF Residuals)

The Hybrid model captures linear sequential patterns with SARIMAX, and then runs a Random Forest Regressor on the SARIMAX residuals to capture non-linear, environmental effects.
In [9]:
# tag: hybrid_model
# Step A: Get SARIMAX in-sample predictions
sarimax_fitted_train = np.exp(sarimax_fit.fittedvalues)
train_residuals = train_df[TARGET] - sarimax_fitted_train

# Step B: Train Random Forest on SARIMAX training residuals
rf_residual_model = RandomForestRegressor(n_estimators=100, random_state=42)
rf_residual_model.fit(X_train_preped, train_residuals)

# Step C: Predict residuals on test set
rf_pred_residuals = rf_residual_model.predict(X_test_preped)
hybrid_pred = sarimax_pred + rf_pred_residuals

# Evaluation
hybrid_rmse = np.sqrt(mean_squared_error(y_actual, hybrid_pred))
hybrid_mae  = mean_absolute_error(y_actual, hybrid_pred)
hybrid_mape = mean_absolute_percentage_error(y_actual, hybrid_pred) * 100
hybrid_r2   = r2_score(y_actual, hybrid_pred)

print("Hybrid Model Test Metrics:")

MODELLING SUMMARY & METRIC INTERPRETATION

Our modeling demonstrates the power of sequential time series when properly configured:

  • Baseline SARIMA yields moderate results but misses short-term agricultural shifts.
  • SARIMAX improves performance by incorporating rainfall and harvested acres, achieving a MAPE of under 7%.
  • The Hybrid SARIMAX-RF Model excels by utilizing RF to explain SARIMAX's residuals, capturing non-linear weather fluctuations.
We recommend the Hybrid model for short-term forecasts, and SARIMAX with Exponentially-Smoothed exogenous features for long-term forecasting.

# Historical project artifacts

The files in this directory are preserved for provenance. They are the original exploratory notebooks, their HTML exports, and the associated project report. Their embedded model outputs and claims pre-date the reproducible pipeline in the repository root and are **not** the authoritative results for the current release.

For current data validation, model code, expanding-window evaluation, metrics, and limitations, use the root README and `src/rice_forecasting/`. The original artifacts are retained unchanged; do not cite their embedded score tables as current results.

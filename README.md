# Rice-Production-Forecasting-SriLanka
Data-driven rice production forecasting in Sri Lanka (1950–2024) using SARIMAX, Random Forest, XGBoost &amp; Hybrid SARIMAX+RF model.   Best: Hybrid (R²=0.9254 | MAPE=5.12%). Full EDA, time-based split, exogenous variables (Rainfall + Harvested Acres) and future forecasts.  Higher National Diploma in Data Science Project.
